# PRD：视频人脸检测与授权换脸工具

## 1. 背景

短视频、影视预演、虚拟形象和数字人内容生产中，经常需要将一个已授权的人脸身份迁移到目标视频中的人物上。现有开源工具通常重模型效果、轻工作流、轻授权管理，容易出现素材混乱、输出不可追溯、合规边界不清的问题。

本项目目标是做一个面向授权素材的视频人脸检测与换脸工具，优先解决“流程清晰、素材可控、结果可追溯”的问题，再逐步提升模型效果和处理速度。

## 2. 目标用户

| 用户 | 需求 |
|---|---|
| 内容创作者 | 将授权人脸替换到视频模板中，生成短视频素材 |
| 影视/广告团队 | 做角色预演、分镜测试、虚拟替身效果验证 |
| 数字人团队 | 将虚拟人脸或授权真人脸迁移到视频动作中 |
| 内部工具团队 | 搭建可审计的人脸处理流水线 |

## 3. 核心需求

### 3.1 输入

- 源人脸图片或短视频：`source_face`
- 目标视频：`target_video`
- 授权清单：`consent_manifest.json`
- 输出目录：`output_dir`

### 3.2 处理流程

1. 读取授权清单，校验源人脸和目标视频是否允许处理；
2. 抽帧并检测目标视频中的人脸；
3. 进行人脸跟踪，形成稳定 face track；
4. 选择需要替换的人脸轨迹；
5. 执行换脸生成；
6. 对输出视频添加 AI 生成水印和元数据；
7. 保存处理日志和参数快照。

### 3.3 输出

- 换脸后视频：`output.mp4`
- 处理报告：`report.json`
- 授权与参数快照：`run_manifest.json`
- 可选调试素材：检测框视频、关键帧、face track 可视化。

## 4. MVP 范围

MVP 不追求一次性实现最强换脸效果，先实现可验证流程：

- CLI 项目骨架；
- 授权清单校验；
- 配置文件解析；
- 人脸检测/换脸模块接口；
- 输出水印与审计接口；
- 单元测试覆盖合规校验和配置解析。

## 5. 非目标

- 不做未授权真人换脸；
- 不做规避检测/去水印；
- 不做实时直播换脸；
- 不在 MVP 中训练自有模型；
- 不承诺任意低清晰度视频都能稳定换脸。

## 6. 合规要求

- 必须提供授权清单；
- 输出默认带可见水印；
- 输出报告保留素材 hash、时间戳、参数、操作者；
- 不提供隐藏 AI 痕迹的选项；
- 不支持公众人物/敏感人物模板库。

## 7. 验收标准

- 无授权清单时拒绝执行；
- 授权清单缺少源人脸或目标视频授权时拒绝执行；
- CLI 能输出明确错误信息；
- 配置能序列化为 run manifest；
- 测试用例全部通过。
