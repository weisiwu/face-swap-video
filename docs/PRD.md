# PRD：爆肝AI 视频换脸 Android App

> 当前事实版本：Android Flutter App + 远端 FaceFusion 生成服务。移动端负责素材选择、上传、进度展示、结果预览/保存；不在本地运行重模型推理。

## 1. 背景

短视频和数字人内容生产中，用户希望用已授权的人脸素材快速生成换脸结果。项目目标是提供一个极简 Android App，让用户在授权素材前提下完成：选择源人脸 → 选择目标图片/视频 → 提交远端生成 → 查看并保存结果。

## 2. 目标用户

| 用户 | 需求 |
|---|---|
| 内容创作者 | 用授权素材快速生成可预览、可保存的换脸素材 |
| 内部运营/测试人员 | 在手机端验证 FaceFusion 远端服务链路是否稳定 |
| 数字人/创意团队 | 用移动端低门槛测试素材效果 |

## 3. 产品形态

- 平台：Android App，minSdk API 29。
- 名称：爆肝AI。
- 主流程：启动页 → 生成页 → 选择素材 → 点击生成 → 必要时登录 → 前台进度/后台等待 → 结果预览/保存。
- 推理方式：所有换脸生成请求提交到远端 API，移动端不执行本地模型推理。
- 风格：极简、少页面、少配置、直接跑通主链路。

## 4. 核心需求

### 4.1 素材选择

- 源人脸：选择一张本地图片。
- 目标素材：选择本地图片或视频。
- 支持 Android 相册/文件选择入口。
- 文件名在 UI 中可读展示，避免长路径污染界面。

### 4.2 生成提交

- 点击“生成/一键开始换脸”前校验源人脸与目标素材是否齐全。
- 未登录用户允许先选择素材；点击生成时弹出登录页。
- 已登录或登录成功后提交远端任务。
- 图片目标走同步接口；视频目标走任务创建 + 轮询 + 下载结果链路。

### 4.3 进度与后台

- 前台处理时展示明确进度与状态文案。
- 上传阶段展示上传字节进度。
- 视频任务轮询阶段展示等待/处理中状态。
- 只有用户把 App 切到后台后，才进入后台转换/后台轮询语义；不能点击转换后立刻显示后台模式。
- 后台完成后通过本地通知提示用户。

### 4.4 结果处理

- 完成后弹出结果预览。
- 视频结果显示首帧缩略图/播放入口。
- 支持保存结果到相册或可访问位置。
- 分享能力、历史记录、失败重试入口暂待产品确认。

### 4.5 登录/注册

- 当前为 Mock 手机号验证码登录。
- 登录页提供“可选读取本机号码”辅助入口；读取失败、拒绝授权或设备不支持时仍手动输入手机号，debug 模式默认使用 mock 手机号。
- 任意非空手机号 + 6 位验证码可通过。
- 当前不接真实短信接口、不持久化 token、不绑定服务端用户。
- 登录触发点：启动页结束后直接进入生成页；未登录用户点击生成时进入登录页，登录成功后返回生成页继续提交。

## 5. 合规要求

- 仅处理用户拥有或已获得明确授权的素材。
- 主界面展示 AI 生成/授权素材提示。
- 不提供去水印、规避检测、隐藏 AI 生成痕迹能力。
- 不支持公众人物、诈骗、色情、诽谤、身份欺骗等用途。

## 6. 非目标

- 不做桌面端或 Web 端替代实现。
- 不在 Android 端运行 FaceFusion/InsightFace 等重模型。
- 不训练自有换脸模型。
- 不做实时直播换脸。
- 不在当前阶段实现会员/额度、微信登录、完整个人中心。

## 7. 验收标准

- Android App 可在 `/tmp/zfj/apps/face-swap-video/app` 下完成 `flutter analyze`、`flutter test`、`flutter build apk --debug`。
- 可选择源人脸和目标素材，缺失素材时给出明确提示。
- 未登录点击生成时进入登录页；登录成功后回到生成流程。
- 图片/视频远端 API 调用路径清晰，错误可见。
- 前台进度、后台等待、完成通知与结果预览链路稳定。
- App 底部展示当前版本号。
