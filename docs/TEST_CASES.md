# 测试用例：爆肝AI 视频换脸 Android App

| ID | 用例 | 命令 | 预期 |
|---|---|---|---|
| B001 | Dart 静态分析 | `flutter analyze` | 0 error / 0 warning |

## 2. 素材选择

| ID | 用例 | 步骤 | 预期 |
|---|---|---|---|
| M001 | 未选择源人脸点击生成 | 只选择目标素材后点击生成 | 提示选择源人脸 |
| M002 | 未选择目标素材点击生成 | 只选择源人脸后点击生成 | 提示选择目标素材 |
| M003 | 选择图片源人脸 | 从相册/文件选择图片 | 源人脸卡片显示已选择状态和可读文件名 |
| M004 | 选择目标图片 | 从相册/文件选择图片 | 目标素材卡片显示已选择状态 |
| M005 | 选择目标视频 | 从相册/文件选择视频 | 目标素材卡片显示已选择状态 |

## 3. 登录触发

| ID | 用例 | 步骤 | 预期 |
|---|---|---|---|
| A001 | 启动后未登录 | 启动页结束 | 直接进入生成页，不强制登录 |
| A002 | 未登录点击生成 | 选择完整素材后点击生成 | 进入登录页 |
| A003 | 发送验证码 | 输入手机号并点击获取验证码 | 进入 60 秒倒计时 |
| A004 | 验证码为空 | 输入手机号，不输入验证码登录 | 提示请输入验证码 |
| A005 | 验证码格式错误 | 输入非 6 位数字验证码 | 提示请输入 6 位数字验证码 |
| A006 | Mock 登录成功 | 输入手机号 + 6 位验证码 | 返回生成页并继续/可重新点击生成 |
| A007 | 退出登录 | 长按生成页账号入口 | 回到未登录显示 |

## 4. 远端 API 链路

| ID | 用例 | 步骤 | 预期 |
|---|---|---|---|
| R001 | 健康检查成功 | 调用 `/api/health` | 返回 200，App 可继续生成 |
| R002 | 健康检查失败 | 断网或服务不可达 | App 展示服务不可用/网络错误 |
| R003 | 图片换脸成功 | 源人脸 + 目标图片 | 上传后下载 jpg 结果并展示预览 |
| R004 | 视频任务成功 | 源人脸 + 目标视频 | 创建 job → 轮询 completed → 下载 mp4 |
| R005 | 视频任务失败 | 服务端返回 failed | App 展示失败信息并允许关闭错误 |
| R006 | 轮询超时 | 长时间未完成 | App 展示超时提示 |
| R007 | 下载失败 | 结果接口异常 | App 展示下载失败信息 |

## 5. 进度与前后台

| ID | 用例 | 步骤 | 预期 |
|---|---|---|---|
| P001 | 上传进度 | 大文件上传 | 进度从 0 开始递增，文案显示上传中 |
| P002 | 处理进度 | 视频任务轮询 | 进度停留在处理中区间，不明显回退 |
| P003 | 下载进度 | 结果下载 | 完成前进度进入 95%+ 区间 |
| P004 | 前台转换 | 点击生成后保持 App 前台 | 展示前台进度，不显示后台转换模式 |
| P005 | 后台转换 | 生成中切到后台 | 后台等待/通知逻辑生效 |
| P006 | 回到前台 | 后台处理中再切回 App | 回到前台进度展示 |
| P007 | 后台完成通知 | 后台任务完成 | 收到本地通知，回到 App 可查看结果 |
